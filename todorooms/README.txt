To Do :) Rooms
==============
1. Unzip, then double-click index.html to open it in your browser.
2. Sign up, create a room, and add tasks.

Notes
- In this download, data is saved in your own browser (localStorage), so rooms
  are NOT shared between different devices or browsers. Sharing a room with
  friends needs a shared database - the Claude-hosted version provides that.
- If login fails when opened from a file, serve the folder locally:
    python3 -m http.server 8000   then open http://localhost:8000
